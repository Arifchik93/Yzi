# Предложение правил автозаключения для шаблона УЗИ мочевого пузыря и предстательной железы

Ниже — набор **комплексных** (многопараметрических) правил по аналогии с действующими правилами для ЩЖ и молочной железы в `conclusionRules.json`.

> Принципы:
> - при подозрении на опухолевый процесс — онконастороженность и маршрутизация;
> - без повторов одинаковых формулировок заключений/рекомендаций;
> - акцент на сочетания признаков (а не одиночные триггеры).

|---:|---|---|---|
| 1 | Мочевой пузырь: форма обычная/овальная, контуры ровные чёткие, стенка 2–4 мм, содержимое анэхогенное, пристеночных/внутриполостных образований нет, дистальные мочеточники не расширены, выбросы с обеих сторон, остаточная моча ≤50 мл; ПЖ: объём в возрастной норме, структура однородная/умеренно неоднородная без очагов, периферическая зона без узлов | Эхографически значимых патологических изменений мочевого пузыря и предстательной железы не выявлено | Плановое наблюдение по клиническим показаниям |

## Примечания по внедрению в rule-engine

- Для уменьшения дублей удобно вынести рекомендации в шаблоны `benign / moderate / high / oncologicalAlert / urgentUrology`.
- Для онконастораживающих правил использовать общий «хвост» рекомендации:  
  «Сопоставление клинико-анамнестических, лабораторных и инструментальных данных. Решение вопроса о необходимости дообследования по клиническим показаниям». 
- Приоритет срабатывания: **ургентные обструктивные** → **онкоподозрение** → **обструктивно-воспалительные** → **доброкачественные/норма**.
- Отдельный триггер маршрутизации к онкологу-урологу: любое подозрительное образование мочевого пузыря/ПЖ **или** настораживающий профиль ПСА (повышение общего и/или неблагоприятное соотношение свободный/общий).
- Технически: при заполнении общего/свободного ПСА автоматически рассчитываются индекс свободный/общий, а при наличии объёма ПЖ — плотность ПСА.
